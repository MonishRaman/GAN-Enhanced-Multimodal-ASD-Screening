STEP 37 — FOLD-SAFE GENETIC GAN VALIDATION
======================================================================

Purpose:
Evaluate genetic GAN augmentation using fold-specific GAN training and stratified cross-validation.

Important leakage-control principle:
For every fold, the GAN is trained only using the real Control embeddings belonging to that fold's training partition. Synthetic samples are therefore not generated using the validation fold.

Number of folds: 5
GAN epochs per fold: 400
Augmentation levels tested: 0, 10, 20, 30

INTERPRETATION:
The purpose of this experiment is to determine whether minority-class genetic augmentation provides stable benefit across independent training/validation folds. The result should be interpreted jointly with the synthetic distribution validation and the independent unseen test evaluation performed previously.

The final 24-sample unseen test set from the original train/test split was not used in this cross-validation experiment.

STEP 36 — GENETIC GAN AUGMENTATION SENSITIVITY
======================================================================

Purpose:
Evaluate how different quantities of GAN-generated Control embeddings affect downstream genetic classification performance.

Original training data:
69 ASD + 23 Control = 92 samples.

Synthetic augmentation pool:
46 synthetic Control embeddings.

Unseen test data:
18 ASD + 6 Control = 24 real samples.

Important methodological statement:
The 24-sample test set was not used for GAN training. The GAN was trained using only the original training set. The test set remained unseen during synthetic sample generation.

A fixed random ordering of the synthetic samples was used so that the augmentation levels were reproducible.

INTERPRETATION
----------------------------------------------------------------------

This experiment is a sensitivity analysis of the genetic GAN augmentation level. It should not be interpreted as test-set hyperparameter optimization. The unseen test set is retained as an independent evaluation set for reporting generalization behavior.

The results should be considered together with the synthetic-data distribution validation from Step 34 and the downstream utility validation from Step 35.
